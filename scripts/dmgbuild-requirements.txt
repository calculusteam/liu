# The DMG styler is fetched from PyPI inside the release job that holds the
# Developer ID identity and the notary key, so an unpinned `pip install
# dmgbuild` let a poisoned release of it — or of either dependency — run with
# those in reach. `pip install --require-hashes -r <this>` refuses anything
# whose bytes differ from the artefacts recorded here. Both the wheel and the
# sdist hash are listed so pip can use whichever it resolves to.
#

# --no-binary=:all:, sdist), then `pip hash` each file.
