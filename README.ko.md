## 기능

### 에이전트 기록

Cmd+K로 명령 팔레트를 열고 "agent history"를 입력하면 설치된 모든 AI CLI(Claude Code, Codex, Copilot, OpenCode, Qwen, Cline, Antigravity)를 탐색할 수 있습니다. 에이전트를 실행하지 않고도 네이티브 방식으로 세션을 재개하거나 대화 내용을 스크롤할 수 있습니다.

### 에이전트 뷰

Liu는 탭 단위가 아니라 분할된 창마다 에이전트를 추적합니다. 탭은 에이전트의 대화 이름을 따르고, 에이전트가 있는 창마다 로고를 하나씩 달며, 출력이 생성되는 동안 활동 바가 흐릅니다. 포인터를 올려두면 패널이 각 창을 나열합니다: 에이전트, 대화 주제, 그리고 `working 1m 12s` 또는 `idle 40s` 알약. 에이전트가 작업 구간을 마치면 그 탭 아래로 카드가 내려오고 완료음이 재생됩니다.

### 에이전트가 에이전트를 실행

창 안의 에이전트는 Liu를 통해 다른 에이전트에게 일을 넘길 수 있습니다: `liu-agent start codex "port the tests"`. Liu가 먼저 묻고, 허락하면 요청한 탭 오른쪽에 붙은 작은 작업 탭으로 실행합니다. 상태를 보여 주는 움직이는 안개 위에 로고가 있습니다. 포인터를 올리면 최신 줄이 보이고, 클릭하면 대화가 열려 다음 턴을 보내거나 멈추거나 그 세션을 창에서 이어갈 수 있습니다. 함께 시작된 에이전트는 팀으로 일하며, 둘이 같은 파일을 건드리면 알림을 받습니다.

### 서브에이전트 탭

에이전트가 자체 서브에이전트를 시작하면(Claude Code의 Agent 도구, Codex, OpenCode, Copilot CLI, Cursor, Qwen Code, Droid, Crush 등) 각각이 에이전트 탭 옆의 작업 탭이 되어, 에이전트 자신의 기록에서 실시간으로 읽힙니다. 서브에이전트 다섯이면 탭 다섯, 안개는 저마다의 그림입니다. 하나에 포인터를 올리면 최신 줄이, 클릭하면 전체 로그가 보입니다. 끝나면 완료 또는 실패로 표시되고 다음 프롬프트에서 사라집니다.

### 음성 프롬프트

**⌘⇧M**을 누르고 말하세요. Whisper large-v3-turbo가 이 Mac에서 실행됩니다 (네트워크도, 계정도, 업로드도 없습니다) 그리고 인식된 단어는 포커스된 창에 입력되므로 Claude Code에서도, 일반 셸에서도, REPL에서도 작동합니다. 실시간 파형이 마이크가 실제로 듣고 있는 것을 보여주고, 멈추면 파형이 고정된 채 그 위로 스캔이 지나가며 음성이 텍스트로 변환됩니다. 마이크를 고르고, Whisper가 아는 100개 언어 중에서 선택하거나, 대신 호스팅형 음성 API를 사용할 수 있습니다.

### 스케치

**⌘K**를 누르고 *Sketch*를 고르세요: 터미널 위에 그림판이 열립니다: 펜, 선, 화살표, 상자, 지우개와 14가지 색, 선 굵기 슬라이더. **P** **L** **A** **R** **E**로 도구를 바꾸고 **⌘Z**로 되돌립니다. **Esc** 또는 **Return**을 누르면 그림이 PNG로 바뀌어 클립보드에 들어가며, 이미지를 읽는 에이전트에 바로 붙여넣을 수 있습니다: 화면 구성을 설명하는 대신 보여 주세요. **⌥+Esc**는 복사하지 않고 닫습니다.

### AI 테마 생성

원하는 디자인을 설명하면 로컬 에이전트가 JSON을 생성하고, Liu가 이를 실시간으로 적용합니다. `~/.config/Liu/themes/`에 저장됩니다. 에이전트는 Liu의 테마 가이드를 받아 25개 색상 항목을 모두 채웁니다. PATH에서 찾은 에이전트만 표시되며, 결과는 설정 → Appearance에서 19개 기본 테마와 함께 나타납니다.

### Markdown 리더 및 에디터

파일 브라우저에서 README, 설계도, 에이전트 노트를 엽니다: 창 안에서 스타일 Markdown 미리보기 또는 원문 편집. 읽기 모드에서 이미지, 코드, 링크 렌더링. 코드 블록에는 언어 라벨과 복사 버튼이 붙고, `![[note]]`는 다른 노트를 문서 안에 삽입합니다.

### 코드 에디터

**⌘K**를 누르고 *Code Editor*를 고르세요: 탭이 작은 IDE가 됩니다: 왼쪽에 탐색기 레일, 오른쪽에 파일, 모든 행과 탭에 파일 형식 아이콘. 테이블 기반 하이라이터 하나가 50개 이상의 언어를 다루며, Vue, Svelte, Astro 컴포넌트 안의 script는 .js 파일과 같은 코드로 분석됩니다. **⌘F**로 찾고, **⌘⇧F**로 바꾸고, **⌘S**로 저장합니다. 상태 표시줄에는 줄/열, 언어, 줄 끝, 인코딩이 표시됩니다.

### 그래프 뷰

폴더의 모든 Markdown 파일 지식 그래프: 노드는 파일, 엣지는 `[[위키링크]]`와 임베드입니다. 힘 기반 레이아웃이 노드를 배치하고, 노트에 마우스를 올리면 이웃이 강조되며, 드래그로 고정하고 클릭하면 열립니다.

### 노트 볼트

모든 노트는 하나의 볼트에 담깁니다. **⌘K** → 노트 생성으로 로컬 에이전트가 Markdown을 바로 작성하고, `[[위키링크]]`가 노트를 연결해 그래프를 채우며, 노트 열기 / 노트 검색으로 어디로든 이동합니다. 터미널의 에이전트는 `$LIU_VAULT`를 물려받아 그곳에 기록하고: **⌘⇧A**는 어떤 노트든 `@source`로 되돌려 보냅니다. 당신과 에이전트가 공유하는 하나의 지식 베이스.

### 내장 알림 시스템

`liu-notify`는 에이전트가 정말로 당신을 필요로 할 때 (오직 그때만) 음성 알림, 데스크톱 배너 또는 맞춤 사운드를 재생합니다. Liu 안에서 실행됩니다. 시작할 때 에이전트에 훅을 추가하고, Liu를 종료하면 훅이 제거되므로 다른 곳에서 실행하는 에이전트에는 영향이 없습니다.

### 토큰 절약

프롬프트에서 <strong>Ctrl+⌘</strong>를 두 번 누르세요: 로컬 Metal 가속 LLM(또는 선택한 에이전트)이 요청이 기기를 떠나기 *전에* 영어 외 텍스트를 영어로 번역합니다. 컨텍스트 창이 줄어들고 API 비용이 크게 감소합니다.

### 내장 SSH

단일 Session 뒤의 완전한 SSH 클라이언트: 실시간 파일 업로드/다운로드, 원격 파일 브라우저, 세션 메뉴, 포트 포워딩(-L / -D), 비밀번호/키/에이전트 인증, known-hosts TOFU, Mosh 재연결 및 최근 세션 기록.

### 명령 팔레트

단일 **⌘K**로 모든 명령, 설정, 호스트, 스니펫, 테마 및 Agent History 항목을 퍼지 검색: 메뉴를 뒤질 필요도, 기억력도 필요 없습니다. 모양도 바뀝니다. `Open Note`는 노트 빠른 전환기, `Search Notes`는 볼트 전체 텍스트 검색, `Go to Heading`은 열린 문서의 개요를 오가는 이동입니다.

### 분할 + 탭

최대 32개 탭, 각각 최대 8개 패널 (H/V 분할 트리). 패널 드래그 앤 드롭. **⌘⇧I**로 모든 활성 패널에 입력을 동시 브로드캐스트. 탭을 밖으로 끌어내면 새 창이 되고, 다른 창의 탭 막대에 놓으면 그 창에 합쳐집니다. 종료 후 다시 열면 Liu가 탭을 복원합니다.

### 하던 곳에서 이어서

Liu는 실행 중에 탭을 저장하므로 종료, 충돌, 재시작 뒤에도 같은 창, 탭, 분할, 폴더가 돌아오며, 각 창은 흐린 `Restored session` 줄 위에 이전 화면을 보여 줍니다. 실행 중이던 에이전트는 셸이 자신의 세션으로 다시 시작합니다(Claude Code, Codex, OpenCode 그리고 재개 플래그가 있는 모든 에이전트). 아무것도 입력되지 않습니다.

### 파일 브라우저

사이드바 로컬 + SFTP 브라우저, 한 번 클릭으로 열기. NSFilePromise로 Finder에 드래그하여 백그라운드 파일 전송. 32 MiB LRU 이미지 캐시. 활성 창의 작업 디렉터리에서 열립니다. Finder 파일을 창에 놓으면 경로가 프롬프트에 입력되고, 그 창이 SSH 세션이면 SFTP로 업로드됩니다.

### 탭 절전

N분간 유휴 상태인 탭이 자동 일시 중단: CPU와 RAM이 거의 0으로 떨어집니다. 클릭하면 떠난 위치에서 즉시 재개, 스크롤백 유지. 프롬프트에서 대기 중인 탭만 절전됩니다. 빌드, 개발 서버, 응답 중인 에이전트가 있으면 깨어 있고, 절전 중에는 스크롤백이 디스크에 저장됩니다.

### 탭 그룹

관련 터미널을 탭 바에서 이름과 색상으로 구분된 그룹으로 묶으세요: 크롬 스타일. 탭의 우클릭 메뉴나 명령 팔레트에서 생성하고, 탭을 드래그해 그룹에 넣거나 뺍니다. 그룹을 접어 탭을 숨기고 절전 상태로 전환해 PTY/SSH 연결을 해제합니다. 8색 팔레트로 색상 변경, 인라인 이름 변경, 그룹 해제 또는 전체 그룹을 한 번에 닫기. 이름과 색상이 지정된 그룹은 재시작 후에도 유지되며 최대 8개까지 사용할 수 있습니다.

### 사이트 매니저

로컬 프로젝트 폴더를 사이트로 등록하고, 한 패널에서 개발 서버를 시작·중지하며 실시간 프로세스 로그를 확인하세요: Local URL, HMR, 상태를 한눈에. 터미널을 떠나지 않고 브라우저 열기, 재시작, 사이트 제거.

### Liu 브라우저

Liu 내장 브라우저에서 요소 선택기를 켜고 실시간 페이지의 아무 요소나 클릭하세요: 버튼, 카드, 어긋난 행. Liu가 해당 요소의 CSS 선택자, 태그, 텍스트, 크기, 전체 HTML을 가져와 컨텍스트 칩으로 에이전트 프롬프트에 바로 인라인으로 넣어줍니다. 스크린샷도, 복사-붙여넣기도 필요 없습니다: 정확한 노드를 가리키면 Claude, Codex 또는 어떤 CLI든 당신이 보는 것을 그대로 봅니다. "이거 고쳐줘", "저거 스타일 바꿔줘" 또는 "이건 왜 가운데 정렬이 안 돼?"에 딱 맞습니다.

## 소스에서 빌드

**의존성**

- macOS, `brew install libssh2`
- SQLite3, stb_truetype, stb_image, cJSON은 `third_party/`에 포함

```bash
git clone https://github.com/calculusteam/liu.git && cd liu

./build.sh              # 대화형 빌드 TUI (macOS)
./build.sh --yes        # 비대화형 권장 빌드
./build.sh --package    # 빌드 + 릴리스 아티팩트

# 또는 CMake 직접:
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(sysctl -n hw.ncpu)
./build/Liu
```

한 번의 빌드로 `liu-notify`(알림 데몬)와 `liu-history`(에이전트 기록 CLI)도 생성됩니다.
