## 機能

### エージェント履歴

Cmd+Kでコマンドパレットを開き、"agent history"と入力すると、インストールされているすべてのAI CLI（Claude Code、Codex、Copilot、OpenCode、Qwen、Cline、Antigravity）を参照できます。エージェントを起動することなく、ネイティブに再開したり、文字起こしをスクロールしたりできます。

### エージェントビュー

Liuはタブ単位ではなく、分割された各ペインのエージェントを追跡します。タブはエージェント自身のチャット名を名乗り、エージェントのいるペインごとにロゴを表示し、出力が生成されている間はアクティビティバーが流れます。ポインタを置くと、パネルが各ペインを一覧します。エージェント、チャットの話題、そして `working 1m 12s` や `idle 40s` と読める状態ピルです。エージェントが一区切りの作業を終えると、そのタブの下にカードが降りてきて完了音が鳴ります。

### 音声プロンプト

**⌘⇧M** を押して話すだけ。Whisper large-v3-turbo はこの Mac 上で動作し、ネットワークもアカウントも不要、何もアップロードしません。認識された言葉はフォーカスのあるペインに入力されるので、Claude Code でも、素のシェルでも、REPL でも使えます。ライブ波形がマイクの実際に聞いている音を示し、話し終えると波形は固定され、その上をスキャンが走りながら音声が文字起こしされます。マイクを選び、Whisper が扱う100言語から選び、あるいはホスト型の音声 API に切り替えることもできます。

### スケッチ

**⌘K** を押して *Sketch* を選ぶと、ターミナルの上に描画シートが開きます。ペン、線、矢印、四角、消しゴム、14 色、線の太さスライダー。**P** **L** **A** **R** **E** でツールを切り替え、**⌘Z** で取り消し。**Esc** または **Return** で絵が PNG になってクリップボードに入り、画像を読めるエージェントにそのまま貼り付けられます。レイアウトは言葉で説明せず、描いて見せましょう。**⌥+Esc** はコピーせずに閉じます。

### AIテーマ作成

外観を説明すると、ローカルエージェントがJSONを出力し、Liuがそれをライブで適用します。`~/.config/Liu/themes/`に保存されます。エージェントには Liu 独自のテーマガイドが渡され、25 の色スロットがすべて埋まります。PATH 上で見つかったエージェントだけが選べ、結果は「設定 → Appearance」で 19 の内蔵テーマと並びます。

### Markdown リーダー＆エディタ

ファイルブラウザで README、設計、エージェントメモを開く：ウィンドウ内でスタイル付き Markdown プレビューまたは raw 編集。読み取りモードで画像・コード・リンクを描画。コードブロックには言語ラベルとコピーボタンが付き、`![[note]]` で別のノートをその場に埋め込めます。

### コードエディタ

**⌘K** を押して *Code Editor* を選ぶと、タブが小さな IDE になります。左にエクスプローラーのレール、右にファイル、すべての行とタブにファイル種別のアイコン。テーブル駆動のハイライターひとつで 50 以上の言語をカバーし、Vue・Svelte・Astro コンポーネント内の script は .js ファイルと同じコードで字句解析されます。**⌘F** で検索、**⌘⇧F** で置換、**⌘S** で保存。ステータスバーには行/列、言語、改行コード、エンコーディングが表示されます。

### グラフビュー

フォルダ内のすべての Markdown ファイルのナレッジグラフ：ノードはファイル、エッジは `[[ウィキリンク]]` と埋め込みです。力学レイアウトが配置し、ノートにホバーすると隣接ノードが点灯、ドラッグで固定、クリックで開きます。

### ノート保管庫

すべてのノートは 1 つの保管庫に収まります。**⌘K** → ノート作成で、ローカルエージェントが Markdown をそこへ直接書き込み、`[[ウィキリンク]]` がノートをつないでグラフを構成し、ノートを開く / ノートを検索でどこへでも移動できます。ターミナルのエージェントは `$LIU_VAULT` を継承してそこへ書き込み、**⌘⇧A** はどのノートも `@source` として送り返します。あなたとエージェントが共有する 1 つのナレッジベース。

### 組み込み通知システム

`liu-notify`は、エージェントが本当にあなたを必要とするとき（そのときだけ）音声アラート、デスクトップ通知、またはカスタムサウンドを再生します。Liu を閉じていても動き続ける、独立したバックグラウンドサービスです。

### トークン節約

プロンプトで **Ctrl+⌘** を2回押す：ローカルの Metal アクセラレーション LLM（または選択したエージェント）が、リクエストがマシンを離れる*前に*非英語を英語に翻訳します。コンテキストウィンドウは縮小し、API 料金は劇的に下がります。

### 組み込みSSH

単一Sessionの完全SSHクライアント：ライブファイル送受信、リモートファイルブラウザ、セッションメニュー、ポート転送(-L / -D)、パスワード/鍵/エージェント認証、known-hosts TOFU、Mosh再接続、履歴。

### コマンドパレット

単一の **⌘K** ですべてのコマンド、設定、ホスト、スニペット、テーマ、Agent History エントリをファジー検索：メニューを探す必要も、筋肉記憶も不要。形も変わります。`Open Note` はノートのクイック切替、`Search Notes` は保管庫全体の全文検索、`Go to Heading` は開いている文書のアウトライン間を移動します。

### 分割 + タブ

最大 32 タブ、それぞれ最大 8 ペイン（H/V 分割ツリー）。ペインのドラッグ＆ドロップ。**⌘⇧I** ですべてのアクティブペインに入力を同時ブロードキャスト。タブを外へドラッグすると新しいウィンドウになり、別ウィンドウのタブバーへドロップするとそこに合流します。終了して再起動しても、Liu がタブを復元します。

### ファイルブラウザ

サイドバーのローカル + SFTP ブラウザでワンクリック開封。NSFilePromise で Finder にドラッグしてバックグラウンドでファイル転送。32 MiB LRU 画像キャッシュ。フォーカス中のペインの作業ディレクトリで開きます。Finder のファイルをペインにドロップするとパスがプロンプトに入力され、SSH セッションのペインなら SFTP でアップロードされます。

### タブスリープ

N 分間アイドル状態のタブは自動的にサスペンド：CPU と RAM がほぼゼロに低下します。クリックすると、中断した場所から即座に再開、スクロールバックも保持。休止するのはプロンプトで待機中のタブだけです。ビルド、開発サーバー、応答中のエージェントがあれば起きたままで、休止中はスクロールバックがディスクに保存されます。

### タブグループ

関連するターミナルを、名前と色分けされたグループとしてタブバー内にまとめます（Chrome スタイル）。**⌘⇧G**、ドラッグ＆ドロップ、または右クリックで作成。グループを折りたたんでタブを隠しスリープさせ、PTY/SSH 接続を解放します。8 色パレットで色変更、インライン名前変更、グループ解除、またはグループ全体を一度に閉じる。名前と色付きのグループは再起動後も保持され、同時に最大 8 グループまで。

### サイトマネージャー

ローカルのプロジェクトフォルダをサイトとして登録し、1つのパネルから開発サーバーを起動・停止し、ライブのプロセスログを確認：Local URL、HMR、状態が一目でわかります。ターミナルを離れずにブラウザを開く、再起動、サイト削除が可能。

### Liu ブラウザ

Liu の内蔵ブラウザで要素ピッカーをオンにし、ライブページ上の任意の要素をクリック：ボタン、カード、ずれた行。Liu はその CSS セレクタ、タグ、テキスト、サイズ、完全な HTML を取得し、コンテキストチップとしてエージェントのプロンプトへそのままインラインで挿入します。スクリーンショットもコピペも不要：正確なノードを指し示せば、Claude、Codex、あるいはどの CLI もあなたが見ているものをそのまま見ます。「これを直して」「それをリスタイルして」「なぜ中央寄せにならない？」に最適。

## ソースからビルド

**依存関係**

- macOS、`brew install libssh2`
- SQLite3、stb_truetype、stb_image、cJSON は `third_party/` に同梱

```bash
git clone https://github.com/calculusteam/liu.git && cd liu

./build.sh              # 対話型ビルド TUI（macOS）
./build.sh --yes        # 非対話の推奨ビルド
./build.sh --package    # ビルド + リリース成果物

# または CMake を直接:
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(sysctl -n hw.ncpu)
./build/Liu
```

一度のビルドで `liu-notify`（通知デーモン）と `liu-history`（エージェント履歴 CLI）も生成されます。
