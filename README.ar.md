## الميزات

### سجل الوكيل

اضغط Cmd+K لفتح لوحة الأوامر، ثم اكتب "agent history" لتصفح كل واجهة سطر أوامر ذكاء اصطناعي مثبتة: Claude Code و Codex وCopilot و OpenCode و Qwen و Cline و Antigravity. استأنف الجلسة محليًا أو تصفح النص دون تشغيل الوكيل.

### عرض الوكلاء

يتتبّع Liu الوكيل في كل جزء مقسوم، لا في كل تبويب فقط. يسمّي التبويب نفسه باسم محادثة الوكيل، ويحمل شعارًا لكل جزء فيه وكيل، وينساب شريط نشاط أثناء إنتاج الإخراج. أبقِ المؤشر فوقه لتسرد لوحة كل جزء: الوكيل وموضوع المحادثة وكبسولة تقول `working 1m 12s` أو `idle 40s`. وعندما ينهي وكيل فترة عمل، تنزل بطاقة أسفل ذلك التبويب ويُشغَّل صوت الاكتمال.

### موجّه صوتي

اضغط **⌘⇧M** وتحدّث. يعمل Whisper large-v3-turbo على هذا الـ Mac (بلا شبكة ولا حساب ولا رفع لأي شيء) وتُكتب الكلمات في الجزء الذي عليه التركيز، فيعمل داخل Claude Code وفي صدفة عادية وفي REPL. يعرض الشكل الموجي الحيّ ما يسمعه الميكروفون فعلًا؛ وعند التوقف يتجمّد الأثر ويمرّ عليه مسح ضوئي أثناء تفريغ الصوت. اختر الميكروفون، واختر من بين كل اللغات المئة التي يعرفها Whisper، أو وجّهه إلى واجهة كلام سحابية بدلًا من ذلك.

### رسم

اضغط **⌘K** واختر *Sketch*: تُفتح لوحة رسم فوق الطرفية; قلم وخط وسهم ومربع وممحاة و14 لونًا ومنزلق لسُمك الخط. **P** **L** **A** **R** **E** لتبديل الأداة و<strong>⌘Z</strong> للتراجع. يحوّل **Esc** أو **Return** الرسم إلى PNG ويضعه في الحافظة جاهزًا للصق في وكيل يقرأ الصور; أرِ التصميم بدل أن تصفه. يُغلق **⌥+Esc** دون نسخ.

### إنشاء مظهر بالذكاء الاصطناعي

صف مظهرًا، وسيقوم وكيل محلي بإصدار JSON، وسيقوم Liu بتطبيقه مباشرة. يتم حفظه في `~/.config/Liu/themes/`. يتلقى الوكيل دليل السمات الخاص بـ Liu فيملأ جميع خانات الألوان الخمس والعشرين. لا يُعرض سوى الوكلاء الموجودين في PATH، وتنضم النتيجة إلى السمات المدمجة التسع عشرة في الإعدادات → Appearance.

### قارئ ومحرر Markdown

يفتح متصفح الملفات README والتصاميم وملاحظات الوكيل: معاينة Markdown منسقة أو تحرير خام داخل النافذة. الصور والأكواد والروابط في وضع القراءة. تحمل كتل الشيفرة تسمية اللغة وزر نسخ، ويُضمّن `![[note]]` ملاحظة أخرى داخل النص.

### محرر الأكواد

اضغط **⌘K** واختر *Code Editor*: يتحوّل التبويب إلى بيئة تطوير صغيرة; شريط المستكشف على اليسار، والملف على اليمين، وأيقونة لنوع الملف في كل صف وكل تبويب. مُبرِز واحد مبني على الجداول يغطي أكثر من 50 لغة، ويُحلَّل السكربت داخل مكوّن Vue أو Svelte أو Astro بالكود نفسه الذي يُحلَّل به ملف .js. **⌘F** للبحث، و<strong>⌘⇧F</strong> للاستبدال، و<strong>⌘S</strong> للحفظ؛ ويعرض شريط الحالة السطر/العمود واللغة ونهاية السطر والترميز.

### عرض الرسم البياني

رسم بياني معرفي لكل ملف Markdown في مجلد: العقد هي ملفات، والحواف هي `[[روابط ويكي]]` والتضمينات. يرتّبها تخطيط موجَّه بالقوة؛ مرّر فوق ملاحظة لإضاءة جيرانها، اسحب للتثبيت، انقر للفتح.

### خزنة الملاحظات

كل ملاحظة تعيش في خزنة واحدة. **⌘K** ← إنشاء ملاحظة يتيح لوكيل محلي كتابة Markdown مباشرةً فيها، وتربطها `[[روابط ويكي]]` وتغذّي الرسم البياني، و"فتح ملاحظة / البحث في الملاحظات" ينقلك إلى أي مكان. الوكلاء في الطرفية يرثون `$LIU_VAULT` ويكتبون هناك أيضًا، و<strong>⌘⇧A</strong> يعيد أي ملاحظة كـ `@source`. قاعدة معرفة واحدة، تتشاركها أنت ووكلاؤك.

### نظام إشعارات مدمج

يتحدث `liu-notify` فقط عندما يحتاجك الوكيل حقًا، وعندها فقط: تنبيه صوتي أو إشعار على سطح المكتب أو صوت مخصص. إنها خدمة خلفية مستقلة تظل تعمل حتى عندما يكون Liu مغلقًا.

### توفير الرموز

اضغط **Ctrl+⌘** مرتين في موجه الأوامر: يقوم LLM المحلي المسرّع بـ Metal (أو الوكيل المختار) بترجمة النص غير الإنجليزي إلى الإنجليزية *قبل* أن يغادر الطلب جهازك. تتقلص نافذة السياق وتنخفض فواتير API بشكل كبير.

### SSH مدمج

عميل SSH كامل خلف Session واحدة: رفع وتنزيل الملفات مباشرة، متصفح ملفات بعيد، قائمة الجلسة، إعادة توجيه المنفذ (-L / -D)، مصادقة كلمة المرور/المفتاح/الوكيل، TOFU للمضيفين المعروفين، إعادة اتصال Mosh وسجل الجلسات.

### لوحة الأوامر

يبحث **⌘K** واحد بشكل ضبابي في كل أمر، إعداد، مضيف، مقتطف، سمة، وإدخال Agent History: لا حاجة للبحث في القوائم. كما تغيّر شكلها: `Open Note` مبدّل سريع للملاحظات، و`Search Notes` يبحث في نص خزنتك كاملًا، و`Go to Heading` ينتقل بين عناوين المستند المفتوح.

### التقسيمات + علامات التبويب

حتى 32 علامة تبويب، كل منها يحتوي على ما يصل إلى 8 أجزاء في أي شجرة تقسيم H/V. سحب وإفلات الأجزاء. **⌘⇧I** يبث الإدخال إلى جميع الأجزاء النشطة في وقت واحد. اسحب علامة تبويب إلى الخارج لإنشاء نافذة، أو إلى شريط علامات نافذة أخرى للانضمام إليها. وبعد الإغلاق وإعادة الفتح يعيد Liu فتح علامات التبويب لديك.

### متصفح الملفات

متصفح محلي + SFTP في الشريط الجانبي مع فتح بنقرة واحدة. NSFilePromise للسحب إلى Finder ينقل الملفات في الخلفية. ذاكرة تخزين مؤقت LRU للصور بسعة 32 ميجابايت. يُفتح في دليل العمل الخاص بالجزء النشط. أسقط ملفًا من Finder على جزء فيُكتب مساره في موجّه الأوامر، أو يُرفع عبر SFTP إذا كان الجزء جلسة SSH.

### سبات علامات التبويب

علامات التبويب الخاملة لمدة N دقيقة تتوقف تلقائياً: تنخفض وحدة المعالجة المركزية والذاكرة العشوائية إلى ما يقرب من الصفر. انقر للاستئناف فوراً من حيث توقفت، مع الحفاظ على التمرير. لا ينام إلا التبويب المنتظر عند موجّه الأوامر؛ فالبناء أو خادم التطوير أو وكيل في منتصف دوره يُبقيه مستيقظًا، وأثناء النوم يُحفظ سجل التمرير على القرص.

### مجموعات علامات التبويب

اجمع الطرفيات المرتبطة في مجموعات مسماة ومرمزة بالألوان مباشرة في شريط علامات التبويب، على غرار Chrome. أنشئ باستخدام **⌘⇧G** أو السحب والإفلات أو النقر بالزر الأيمن. اطوِ مجموعة لإخفاء علاماتها وإسباتها، مما يحرر اتصالات PTY/SSH الخاصة بها. أعد التلوين من لوحة من 8 ألوان، أو أعد التسمية داخل السطر، أو فُكّ المجموعة، أو أغلق مجموعة كاملة دفعة واحدة. تبقى المجموعات المسماة والملونة بعد إعادة التشغيل: حتى 8 في وقت واحد.

### مدير المواقع

سجّل مجلدات المشاريع المحلية كمواقع، وابدأ وأوقف خوادم التطوير من لوحة واحدة، وراقب سجلات العمليات مباشرة: عنوان URL المحلي وHMR والحالة بنظرة واحدة. افتح المتصفح أو أعد التشغيل أو أزل موقعاً دون مغادرة الطرفية.

### متصفح Liu

فعّل أداة اختيار العناصر في متصفح Liu المدمج وانقر على أي شيء في صفحة مباشرة: زر، بطاقة، صف غير محاذٍ. يلتقط Liu محدّد CSS الخاص به ووسمه ونصه وحجمه وكامل HTML ويضعه مباشرةً داخل موجّه وكيلك كشريحة سياق. بلا لقطات شاشة، بلا نسخ ولصق: أشِر إلى العقدة المحددة بدقة، وسيرى Claude أو Codex أو أي واجهة سطر أوامر تمامًا ما تراه. مثالي لـ "أصلح هذا"، "أعد تنسيق ذلك"، أو "لماذا هذا غير متمركز؟".

## البناء من المصدر

**الاعتماديات**

- macOS، `brew install libssh2`
- SQLite3 وstb_truetype وstb_image وcJSON مضمّنة تحت `third_party/`

```bash
git clone https://github.com/calculusteam/liu.git && cd liu

./build.sh              # واجهة بناء تفاعلية (macOS)
./build.sh --yes        # بناء موصى به غير تفاعلي
./build.sh --package    # بناء + حزمة الإصدار

# أو CMake مباشرة:
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(sysctl -n hw.ncpu)
./build/Liu
```

يبني أيضًا `liu-notify` (خدمة الإشعارات) و`liu-history` (واجهة سجل الوكلاء).
